# AEROBURST — FRONTIER

空を、連鎖しろ。760×960mの浮遊大陸を高速で駆け、5つの中枢を解放して天空の王座へ挑む、PCブラウザ向け3Dアクションです。

## 起動

Node.jsとpnpmは `mise.toml` で固定しています。

- Node.js **24.18.0**
- pnpm **11.24.0**

```powershell
cd C:\Users\kawau\dev\AEROBURST
mise trust
mise install
mise exec -c "pnpm install"
mise run dev
```

ブラウザで http://127.0.0.1:5173 を開きます。既に開発サーバーが動いている場合は、そのURLを直接開けます。

## 操作

| 入力 | 動作 |
| --- | --- |
| WASD | カメラ基準で移動 |
| マウス | 視点操作 |
| Space | 二段ジャンプ。空中で長押しして滑空。ブースト併用で上昇 |
| Shift | 視点方向へブリンク。長押しで高速ブースト |
| 左クリック長押し | 連続斬撃 |
| 右クリック | 地上で打ち上げ、空中で急降下攻撃 |
| F | グラップル：70m以内の照準内の敵へ接近・追撃 |
| E | サイクロン：周囲の敵を吸引して回転斬り |
| R | フォトンランス：視点方向へ80mの貫通光線 |
| C | イージス：防壁・敵弾反射・反撃衝撃波 |
| Z | ウィングドローン：8秒間の自動援護射撃 |
| X | オーバードライブ：8秒間の攻撃強化・ブースト消費ゼロ |
| Q | ゲージ100%で半径48mのエアロバースト |
| M | 全域マップと目的地指定 |
| Esc / P | ポーズ |

ブリンクは上下を含む実際の視点方向に進み、敵やWASDの方向には引き寄せられません。壁に当たると停止または滑るため、壁抜けはしません。敵を倒すとブリンク3回分と燃料が回復し、スキル待機時間も短縮します。

緑のパッドは大ジャンプ用、道路の光るゲートはブースト補給と加速用です。敵の朱色の円は攻撃予告。落下時は耐久値を20消費して最後に解放した中枢へ復帰します。

マウス固定に対応しないブラウザ環境では、中央ボタンを押しながらドラッグ、または左右矢印キーで視点を変更できます。ゲーム画面に代替操作を表示します。

## 内容

- 港、庭園、白亜の回廊、観測所、発電区、天空の王座の6地区。最初の5地区は自由な順に攻略できます。
- 通常地区は各2編隊。最終決戦を含む計157体。
- 近接型・射撃型・飛行型・重装型の敵。4種類の攻撃と第2形態を持つボス。
- 6つの追加アクティブスキル、三段目の回転斬り、空中コンボ、残像、範囲衝撃波、貫通光線。
- 基本ブースト46m/s、ゲート加速68m/s、二段ジャンプ・滑空・ブースト上昇。
- 全域マップ、目的地の距離と方位、周辺レーダー、各技のクールダウン表示。
- 中枢解放で最大耐久+15、全回復、復帰地点更新。15個の探索データキャッシュ。
- ポーズ・リトライ・操作説明・設定・結果画面。
- 音量、マウス感度、画面揺れ、フラッシュ、高画質／軽量の切り替え。
- 最高得点と設定をブラウザのlocalStorageに保存。保存が無効な環境でもプレイできます。

キーボードとマウスを使用してください。スマートフォン用タッチ操作は未実装です。

## 検証とビルド

```powershell
mise run check
# 個別に実行する場合
mise exec -c "pnpm typecheck"
mise exec -c "pnpm test"
mise exec -c "pnpm build"
mise exec -c "pnpm preview"
```

ビルド成果物は `dist/`。静的ホスティングで配信できます。APIキー、バックエンド、データベースは使用していません。フォントと物理エンジンも同梱します。

## 構成

- `src/game/engine.ts` — 固定時間刻みの移動、スキル、敵AI、地区進行、スコア。`core.ts` から公開。
- `src/game/world.ts` — 地区座標・道路・ゲート・収集物・フィールド境界の共通定義。
- `src/game/Landscape.tsx` — 広域地形、建築、道路、中枢、ゲート、収集物の描画。
- `src/game/Scene.tsx` — 機体・敵の描画、Rapierの衝突、実カメラ方向の取得。
- `src/game/SkillEffects.tsx` — 48枠のスキル演出、残像、防壁、随伴ドローン。
- `src/FlightHUD.tsx` — 7枠のスキルバー、マップ、ナビ、レーダー。
- `src/game/audio.ts` — Web Audioの効果音。最初のユーザー操作で音声を有効化。
- `src/App.tsx` — 入力、タイトル、HUD、設定、結果画面。
- `src/game/core.test.ts` — 視点方向ブリンク、移動、全スキル、地区攻略、勝敗・リセットの26件のテスト。
- `docs/verification.md` — 検証手順と確認範囲。

状態のシミュレーションは60Hz、HUDへの通知は約13Hz。3D描画はReactの毎フレーム再レンダリングを使わず、固定数のオブジェクトを更新します。物理エンジンは床・足場・キャラクターの衝突を担当し、アクションの速度や打ち上げはゲーム側で制御します。

`?qa=1` を付けた開発サーバーだけに `window.__AEROBURST__` を公開し、検証時の状態観測に使います。本番ビルドには公開しません。
