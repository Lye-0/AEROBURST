## ブラウザ操作

agent-browserで初期画面・操作要素を確認。通常のChromiumでは出撃ボタンからPointer Lockが成功。

Playwright MCP環境ではPointer LockがWrongDocumentErrorを返したため、中央ボタンドラッグ・左右矢印による代替操作を実装した。

確認した流れ:

1. タイトル → 出撃 → WASD移動 → Spaceジャンプ → Shiftダッシュ → マウス斬撃。
2. 通常3セクターの増援とボスを含む57体の撃破 → 勝利画面。カメラ方向のみ開発用インターフェースで最寄りの敵へ向け、移動・攻撃・ダッシュ・必殺技はPlaywrightのキーボード／マウス入力で実行。敵HPや勝敗状態を変更せず完走。
3. 足場の手前へ検証用の開始位置を設定。W移動で壁の手前（z ≈ −10.52）に停止。ジャンプで足場へ上がり、右クリックの急降下から足場上（y ≈ 3.53）に着地。
4. ポーズ中にゲーム時間が停止し、再開可能。
5. 開発用インターフェースで致死ダメージを与え、敗北画面 → 再出撃。HP100、得点0、コンボ0、最初のセクターに初期化。
6. 音量・画面揺れ・描画品質・最高得点が再読み込み後も保存される。
7. 1440×900、1280×640、390×844で表示確認。1280×640でタイトルとフッターの重なりなし、390×844で横方向のはみ出しなし。
8. 操作説明ダイアログでTabキーによるフォーカス循環を確認。
