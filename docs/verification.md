# FRONTIER 拡張版の動作検証

2026-09-17、WindowsのChromium系ブラウザで実施。

## 自動チェック

mise run check：型チェック、Vitest 26件、本番ビルドに成功。

重点項目：視点方向のブリンク（敵・WASDに依存しない、上下角、実カメラ方向、壁衝突）、二段ジャンプ、高速ブースト、燃料切れ後の回復、チェックポイント復帰、通常攻撃と急降下、6つの新技、必殺技、地区の自由攻略、収集物の重複防止、最終ボス解放、勝敗とリセット。

## 実操作による通し検証

agent-browserで起動とタイトルを確認後、Playwright MCPのEdgeで実操作を検証。Chrome MCPは既存ブラウザのプロファイル使用中だったため、別のブラウザを使用した。

- 出撃から6地区すべてを解放し、157体を撃破して勝利画面まで到達。
- 攻略順は港 → 庭園 → 観測所 → 発電区 → 回廊 → 王座。移動はWASDとShift、攻撃はマウスと各スキルキーで行った。
- カメラの向きだけを開発用インターフェースで目的地・敵へ合わせた。プレイヤーの位置、敵HP、ダメージ、地区の解放状態は変更せずに通しで確認。
- 最終ボスHPが半分を下回ると第2形態へ移行し、最終撃破後に勝利した。最大コンボ185、検証時ゲーム時間約82秒（自動照準付きの検証であり、人の所要時間の評価ではない）。
- 新技6種類、必殺技、グラップルと攻撃の接続、撃破時の回復と待機時間短縮を確認。
- 視点を斜め上へ向けたブリンクで、取得したカメラ方向とブリンク方向が一致し、実際に上昇・横移動することを確認。
- Shift＋Spaceで100m超の飛行と上昇を確認。
- Mキーでマップが開いてゲームが停止。地区選択で目的地が変更され、プレイ再開。
- 通常地区の解放で耐久上限・チェックポイントを更新。5中枢の解放後に王座をアンロック。
- 移動中のデータキャッシュ取得を確認。

## 本番・表示・性能

- 本番プレビューでも出撃、グラップル、サイクロン、ドローン、通常攻撃、ポーズ、マップを確認。
- コンソールエラー0件。Rapierの初期化引数の非推奨警告1件は既存の依存パッケージ由来。
- 本番で開発用の window.__AEROBURST__ が公開されないことを確認。
- 1440×900でフィールド・戦闘・全域マップ、1280×720で7枠のスキルバーと左右HUDの非重複を確認。
- 本番・高画質の戦闘中、requestAnimationFrame間隔175フレームの中央値約16.7ms、95パーセンタイル約16.8ms。特定環境の短時間観測であり、全端末での60fps保証ではない。
